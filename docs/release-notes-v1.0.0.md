# Play v1.0.0

## Türkçe

İlk sürüm. Play; sade, koyu temalı bir film/dizi istemcisidir. **Uygulama hiçbir içerik, addon veya eklenti içermez.** Kaynaklar, kendi eklediğin adreslerden gelir; eklentiler üçüncü taraflarca yazılır.

### Öne çıkanlar
- TMDB'den beslenen ana sayfa, arama ve ayrıntılı film/dizi sayfaları
- Eklentilerden (Nuvio addon'ları ve JS eklenti depoları) paralel kaynak toplama, tek dokunuşla oynatma
- Media3 oynatıcı: kaldığın yerden devam, hız, ileri-geri
- Altyazı: tek seçici, dile göre gruplama, otomatik kodlama tespiti, elle senkron
- Çevrimdışı indirme ve indirilenleri altyazılarıyla izleme
- Kütüphane: favoriler, geçmiş, indirilenler
- Reklam engelli web sitesi görünümü
- Android TV, tablet ve kumanda desteği
- Türkçe ve İngilizce arayüz

### Kurulum
1. `Play-v1.0.0.apk` dosyasını indir.
2. Telefonda "bilinmeyen kaynaklardan yükleme" iznini tarayıcın/dosya yöneticin için aç.
3. APK'yı aç ve yükle. Android 7.0 (API 24) ve üstü gerekir.
4. Uygulamayı açıp Ayarlar > Eklentiler'den bir adres ekle.

### Notlar
- Dosya, bu projeye özel bir anahtarla imzalanmıştır; güncellemeler aynı anahtarla gelecektir.
- Bu ürün TMDB API'sini kullanır ancak TMDB tarafından onaylanmamış veya sertifikalandırılmamıştır.
- Her reklamın engelleneceği vaat edilmez.

## English

First release. Play is a simple, dark-themed movie and series client. **The app ships with no content, addons or plugins.** Sources come from URLs you add yourself; plugins are written by third parties.

### Highlights
- Home, search and detail pages powered by TMDB
- Parallel source gathering from addons (Nuvio addons and JS plugin repositories), one tap to play
- Media3 player: resume, speed, seek
- Subtitles: a single picker, language grouping, automatic encoding detection, manual sync
- Offline downloads and offline playback with subtitles
- Library: favorites, history, downloads
- Web view with ad blocking
- Android TV, tablet and remote support
- English and Turkish UI

### Installation
1. Download `Play-v1.0.0.apk`.
2. On your phone, allow "install unknown apps" for your browser/file manager.
3. Open the APK and install. Requires Android 7.0 (API 24) or newer.
4. Open the app and add a URL in Settings > Addons.

### Notes
- The file is signed with a project-specific key; future updates will use the same key.
- This product uses the TMDB API but is not endorsed or certified by TMDB.
- Not every ad is guaranteed to be blocked.
